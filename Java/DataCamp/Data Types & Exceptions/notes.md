# Advanced Data Types
- Building a POJO is about creating a straightforward Java class following a few rules. POJO classes are simple and independent; they don't extend other classes or implement interfaces. The main task is to define the fields and create getter and setter methods to access them. Here, you create a POJO for transporting savings account data in a Java application.
- Integer and Boolean are wrapper classes. char is a primitive type, but Char is not any type. The wrapper type for char is Character. String is not a wrapper class or a primitive type. Given that the names of primitive types and wrapper classes are similar or the same except for case, it takes a second to identify a wrapper from a primitive.
