# Encapsulation and inheritance
- access modifier - public, private, static
- centralizing code w/ inheritance
- class Toyota extends Car{}
- Introducting base class
- subclass -> class that inherits base class - inhertis all public properties
- super() - calls constructor of base class
- abstract class - don't have code implementation
- abstract class Car { abstract void drive()}}
- concrete methods - method w/ implementation
- Limitations of inheritance - we can't selectively inherit 

# Interfaces and Polymorphism
- interfaces - selectively inherit - implements
- values can't be changed
- polymorphism - allow object to exist in multiple forms
- @Override - allows to create custom method impl
- overriding implementation method
- overloading - allows method w/ same name to have different impl
- overloading the constructor
